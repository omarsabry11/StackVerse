# 🚀 StackVerse

Welcome to **StackVerse**, a modern learning platform built with **Next.js**, designed to provide a smooth experience for browsing, exploring, and managing courses.  
The project focuses on performance, scalability, and a clean user experience using modern frontend technologies.

---

## 🌐 Live Demo

🔗 [View Live Website](https://stack-verse-4wjp.vercel.app/en)

---

## ✨ Features

- ⚡ **Next.js App Router** – Modern full-stack React framework
- 🌍 **Multi-language Support** – Powered by `next-intl`
- 🎨 **Modern UI Design** – Built with **Tailwind CSS 4**
- 🌙 **Dark / Light Mode** – Using `next-themes`
- 🎬 **Smooth Animations** – Powered by `framer-motion`
- 📩 **Contact System** – Integrated with `resend`
- 🔔 **Notifications** – Using `React Toastify`
- 📱 **Fully Responsive Design** – Mobile, Tablet & Desktop support
- 🧩 **Reusable Components** – Clean and scalable architecture
- 🚀 **High Performance** – Optimized rendering with Next.js
